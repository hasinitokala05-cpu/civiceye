# 👁️ Civic Eye

**Civic Eye** is a web-based platform that enables citizens to report civic issues such as potholes, garbage dumps, broken streetlights, water leakage, and other public infrastructure problems. The platform helps bridge the gap between citizens and local authorities by providing a simple and efficient way to report, track, and manage complaints.

---

## 📌 Features

* 📝 Report civic issues with details
* 📍 Add location of the issue
* 📷 Upload images as proof
* 📋 View all reported complaints
* 🔄 Track complaint status
* 👤 User-friendly interface
* 💻 Responsive design

## 📖 How It Works

1. User opens the Civic Eye application.
2. User reports a civic issue by filling out the complaint form.
3. The issue is submitted with location and image details.
4. Complaints are stored and displayed in the system.
5. Authorities can review and update the complaint status.
6. Users can track the progress of their reported issues.
